# Plugchoice SDK for iOS

The Swift package `PlugchoiceSDK`. Add it with Swift Package Manager from `https://github.com/plugchoice/mobile-sdk`, then follow the [iOS guide](https://developer.plugchoice.com/sdk/ios).

An example app is in [`Example`](Example).

## Development

From the repository root:

```sh
xcodebuild -scheme PlugchoiceSDK -destination 'platform=iOS Simulator,name=iPhone 17' test
```
