# Plugchoice SDK for Android

The library `com.plugchoice:plugchoice` (module [`plugchoice`](plugchoice)). Follow the [Android guide](https://developer.plugchoice.com/sdk/android) to add it to your app.

An example app is in [`example`](example).

## Development

```sh
./gradlew :plugchoice:testDebugUnitTest   # unit tests
./gradlew :example:installDebug           # the example app on a connected device
```
